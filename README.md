# focus-agri-tech-seo-audit

A rapid SEO audit of focusagritech.com, prepared in 2025 as a one-hour assignment for a job application. It identifies the highest-impact technical, on-page and off-page issues and turns them into a prioritised 30/60/90-day plan with measurable targets.

**Note**: This is a time-boxed triage, not a full audit. See Limitations.

**Table of Contents**

1. About the Website

3. Findings
4. 30/60/90 Day Action Plan
5. Proposed Success Metrics

**About the Website**

Focus Agritech was founded in 2020 as India's digital-first community platform connecting agri-startups, incubators, researchers, investors, institutions and farmers. It supports leadership talks, funding news, startup visibility and sector events.

**Approach and Tools**

1. Ahrefs	Site audit data: broken links, server errors, missing H1s, image issues
2. Manual audit	Review of pages, content quality, internal linking and CTAs
3. Gamma	Building the presentation

**Issues were ranked by their likely impact on crawlability, user experience and rankings**

| Priority | Opportunity | Action |
|---|---|---|

| Medium | Audience retention | Email nurture sequences |

Priorities are my own assessment based on likely impact and effort. TBD counts should be filled from the Ahrefs export.

**30/60/90 Day Action Plan**

| Phase | Goal | Key Tasks |
|---|---|---|
| **Days 1-30** | Foundation and quick wins | Keyword research; fix 404/5xx errors; compress and optimise images; verify HTTPS and redirects; correct URL structures; update meta and H1 tags; add alt text; deploy schema for articles and events |
| **Days 31-60** | Content and authority | Publish in-depth guides; build content hubs; start guest posting and outreach; launch LinkedIn/Quora engagement; begin email nurture sequences |
| **Days 61-90** | Optimise and scale | Continuous technical monitoring; content refreshes with multimedia; GA4 funnels; Core Web Vitals tracking; expand backlink profile; monthly KPI reporting |

These are proposed goals. A real engagement would first set a baseline from Search Console and analytics.

**Limitations**

1. Based on one short review, not a complete crawl and analysis.
2. Example URLs are illustrative, not exhaustive.
3. The site may have changed since 2025.
4. Off-page SEO is covered as recommendations, without a full backlink or competitor analysis.
5. A full audit would add Search Console and analytics data, keyword and competitor research, and Core Web Vitals measurements.
